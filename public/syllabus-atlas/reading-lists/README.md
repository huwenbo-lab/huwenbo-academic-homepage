# 十方向阅读工作台：从这里开始

版本：2026-11-20。第二阶段：专题阅读清单、规范书目及出处核验。

本轮把此前的十方向、84专题知识结构推进为可直接执行的阅读清单：**287部独立作品、316次方向内使用、330条专题阅读用途**。266部作品有核对后的DOI，其余21部以出版社或机构记录定位。来自56条课纲/书单来源的条目、2部按课程方法补全书目的作品以及8部整理者补充作品均有来源区别。

## 文件怎么用

日常管理打开 **Syllabus_十方向阅读工作台_20261120.xlsx**。它包含“阅读导航”“阅读清单”“文献总表”“课纲出处”“专题覆盖”五张表：导航查看各方向规模；阅读清单按方向、专题、优先级筛选并记录状态和笔记；文献总表保存每部作品唯一ReadID；课纲出处保存原课单元与必选读标记；专题覆盖检查已有入口和缺口。

希望连贯阅读时，进入 **lists/T01.md—T10.md**。每份清单都先给本领域的问题边界和第一轮顺序，再按专题提供完整引文、为什么读、原课出处以及版本说明。第一轮是可开始的学习顺序，深化用于推进具体问题，方法工具按研究需要调用；方法工具不代表价值较低，也不要求把每个方法都读完才能开始实质阅读。

**reading_library.ris、reading_library.bib、reading_library.csl.json** 是同一287部作品的可导入格式；已有Zotero同步分类时，不应再次整包导入，以免人为制造重复。**reading_library.json** 保存完整的作品—专题—课纲关系；**专题覆盖与来源核验.md** 和 **source_audit.csv** 保存覆盖和来源状态。包内不含原课PDF、论文全文、检索缓存或私人Zotero目录。

## 本轮做了哪些书目校订

核验优先对照原课位置，再核作者、题名、出版类型、年份、卷期页码和DOI。将“课纲上确实列了什么”与“当前规范出版版本是什么”分开保存；不能由出版社网页倒推某篇一定是课程必读。主要修正包括误连DOI、正式刊与工作论文混用、在线年与卷期年混用、同名书评、原书与重印本、编者和译者身份。

Bansak等2021年的Conjoint Survey Experiments是《Advances in Experimental Political Science》中的书章，原GESIS课纲误附DOI，已改为10.1017/9781108777919.004。Schuessler与Freitag2020年的Power Analysis for Conjoint Experiments仍按已核到的SocArXiv预印本保存，未升级成期刊论文。Auspurg与Jäckle的First Equals Most Important?按2017年正式刊版46(3):490–539保存，同时记录原课2015在线年与页码误写。

Kiley与Vaisey2020年的文化变化研究明确附2022年Corrigendum的DOI及阅读提醒。Cox1972年正文页码187–202与课纲含讨论的阅读范围187–220同时保存。Railsback与Grimm首版保留2011发行与2012版权/书目年的差异，未把版本差异一概当作错误。所有这些判断及其核验链接都可回到具体作品查看。

## 完成范围和仍待处理的部分

以第一阶段保留的89条整份来源/版本及30组精选单元为边界，完成一轮有选择的博士阅读清单。未穷尽抄录119条来源的全部参考文献；书目核验不代表全文精读。

本轮沿用89条整份来源/版本与30组精选单元的保留边界，并从56条来源选出适合当前阅读结构的读物。另有9条前阶段待补来源继续单列；不是把它们重新纳入已完成的119条。当前清单使84个专题均有入口，但理论传统对读、全球南方、东亚内部制度比较、多维婚配、复杂抽样等领域仍有明确的深化缺口。

Stanford R3-022的三条方法书目保留前轮转录关系，出版信息已独立核实；Toronto S068被人机验证阻断，Delhi S079当前未取得原件。Mannheim1952章末页存在版本引文差异，保留课纲页码并标注待核。以上状态均未用“下载成功”或“有DOI”替代核验。

阅读理由属于本项目的课程整合判断，不能当成每部文献全文论点的摘要；本轮完成的是阅读清单及书目准备，实际全文精读应在工作簿继续记录。

## 领域导读与阅读进度（工作台增强）

新增 [知识地图网页](guide.html) 和 GitHub 可直接阅读的 [KNOWLEDGE_MAP.md](KNOWLEDGE_MAP.md)，围绕十个研究领域的核心问题、理论争论、方法边界，提供五条跨方向知识连接与五组研究项目阅读路径。对应字段链接直接跳转筛选后的书目或第一轮阅读。导读是根据课纲与书目形成的初步综合，**不等于已逐篇阅读全文或完成系统性文献综述**。

阅读页面支持“计划读／正在读／已读完／未开始”的状态标记、状态筛选和进度概览。进度由浏览器本地存储保存，**不会上传到 GitHub 或 Zotero**。如需换设备或保留备份，使用“导出进度 JSON”和“导入进度 JSON”；导入会覆盖当前浏览器的状态，作品用稳定 ReadID 对应。该个人状态与作品原始书目 `reading_status`（核验和全文阅读说明）不同。
